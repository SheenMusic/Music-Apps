# Music-Apps 课程视觉规范

本规范取代“新旧PNG逐像素一致”作为课程视觉迁移验收。历史测试、诊断与审批材料保留，不再作为这次设计统一的发布门禁。全站主题仍由 `assets/site-visual.css` 唯一提供；非课程页面不接入新规则。

## 三层架构与加载

1. `assets/course-visual.css`：明确以 `html[data-course]` 限定课程。直接使用site背景、面板、文本、边框、焦点、成功/错误及阴影变量；新增变量仅描述课程尺寸、间距和动效。
2. ET `shared/styles/base.css`（音高训练）、`quiz-base.css`（ET01/02听辨）；MT `practice-base.css`（五个Practice）、`learning-base.css`（三个Learning）。相同组件共享；不同教学控件使用独立选择器，不合并教学引擎。
3. 单课style或既有CSS：特有白板、谱例、键盘、特殊音程/目标采集布局与课程专属响应式。

加载次序：类型共享CSS → 保留的课程CSS → 现有site主题 → 必要单课style → course视觉规范。单课选择器零特异性课程前缀防止外溢；site主题与最后的课程规范统一普通UI。教学颜色和几何保持在原教学岛中。相同普通组件的历史不同实现统一为一份类型规则，不追求保留旧CSS差异。

## 统一设计值

| 项目 | 规范 |
|---|---|
| 背景/主题 | `--site-bg`/`--site-panel`，跟随系统Light/Dark |
| 普通内容宽度 | 640px；Learning常规720px、横屏宽屏1120px，用于白板与解释并排 |
| 页面内边距 | clamp(12px,3vw,24px)，兼顾安全区 |
| 卡片 | site圆角8px、site边框1px、site阴影，内边距clamp(16px,3vw,24px) |
| 字体 | `--site-font`；正文15px/1.6，主标题clamp(24px,4vw,32px)/1.3、700字重 |
| 普通按钮 | 高度至少44px、8px圆角、14px/1.5、500字重；可换行，焦点site-focus |
| 控件 | 44px最小触控高度；教学键盘/谱例内部控件不套普通按钮规则 |
| 状态 | success/error使用site语义前景、背景、边框；禁用site-soft/site-muted；ET播放/录音/锁定语义保留 |
| 进度 | 6px轨道、圆端，site-accent；题号状态按原JS管理、样式按类型共享 |
| 结果/历史 | 普通卡片规范，表格/长内容在必要容器内滚动，不使页面横向溢出 |
| 响应式 | 430px窄屏允许标题/导航换行；Learning保留教学白板与解释区独立滚动和方向布局 |
| 动效 | 控件/进度160ms；继续使用site入口动效；减少动态模式禁用课程动画、过渡和平滑滚动 |

## 教学边界

ET构唱与模唱独立，旋律参考音和和声双音采集各自保留原DOM、事件、报告、算法。音高偏差仪表、低/高音锁定与准确判定颜色不被普通UI样式覆盖。

MT五线谱、音乐键盘、音程标记与教学白板保留本地教学调色板。普通卡片统一不意味着把白板颜色、谱例字号或黑白琴键替换成主题UI。课程URL、题库、题序、判题、持久化、计时和导航不变。

## 验收

以固定工程起点保护全26页body及所有JS，运行既有三课行为测试及全Practice题库/答题检查。真实Chromium检查320、390、430、768×1024、1024×768、1280×900，两种主题，包含课程活动状态。检查主题、普通卡片、按钮、横向溢出、控件重叠与文本裁切、脚本错误和资源404。截图供新设计观察，不和旧PNG比较。

Dashboard/Catalog/其他非课程源码必须与工程起点一致；用课程CSS注入检查验证作用域。已知TODO不伪装成通过。真实权限/音频/人声/Safari仍需要发布后的设备验证。

报告按钮保留原静态内联背景/文字声明，以严格保持教学body与事件契约；共享规范使用两条只限 `#reportCard .mic-btn` 的必要important声明适配主题。这是有范围的兼容例外，不涉及音高反馈或全站覆盖。播放用warning语义，录音用error语义，采集锁定/完成用success语义；文案、判定和录音状态仍由原JS管理。
