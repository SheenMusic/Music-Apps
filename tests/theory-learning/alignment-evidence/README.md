# MT Learning 演示与讲解独立对齐：实施证据

起点：`refactor/mt-learning-framework@af053840284319439cf7d22142fe38b4decf4d4c`，起始工作区干净。范围仅为 MT01/02/06 Learning 的布局显示与相关滚动；课程原文、音符/音高、Quiz、音频、URL、Practice、ET、Dashboard、Catalog、报告核心与部署配置未修改。

## 根因与修正

1. MT01 度数总览及 MT02 谱例的多层100%高度包装占满 Board，内部SVG仍在包装顶部，因而“包装已居中”不等于音乐居中。MT01第9步旧可见边界中心偏差约−208.69px，MT02第1/3步约−230.38px。
2. 即使SVG盒子居中，其上下透明留白不对称仍会使可见谱线/谱号/音符偏移；MT01第1步旧偏差约+21.11px。
3. 上版讲解内容层无条件margin-block:auto，将上下布局正文也推到下方区域中部。本版默认margin-block:0，仅定义实际双栏grid的同一CSS规则设置auto；JS也只在实际双栏时执行居中FLIP。
4. MT02性质图有意保留未揭示的网格单元；新增完整可见边界测试发现第20步仍偏−18.25px。专用显示视口按已揭示文字计算，保留所有原单元、CSS揭示类与教学顺序，不以空白占位作为中心。

演示使用独立的内在高度`.theory-board-content`，安全自动外边距分配上下空间；超高组件外边距归零、可独立滚动。共享SVG视口只裁除透明纵向留白并保留描边余量，绘图路径、音符参数和横向宽度不变。音频按钮保留在Board右上角，不属于居中内容。

根音/冠音及旋律引线属于演示整体。原旋律绝对坐标计算改为SVG getScreenCTM映射，并在缓存恢复/尺寸变化时响应共享布局事件，原音名标签定位函数复用。标签预留空间以共享排版/间距计算；不逐帧修改谱例偏移，不重画无须更新的谱表。

讲解与演示独立：双栏短内容居中，240ms FLIP让旧段落平滑上移；上下布局保持顶部，只渐显新文。两种布局在溢出后都只滚讲解区；快照与读者接管保留，尺寸变化取消旧布局中待执行定位。
