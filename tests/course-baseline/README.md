## 工具与运行

没有现有课程测试目录、package.json 或课程测试脚本；`scripts/build-works.py` 是作品页面生成器，不适用于本次测试。复用环境已有 Node test runner、Playwright 和系统 `/usr/bin/chromium`，没有安装依赖、没有新增构建步骤。

```bash
node --test tests/course-baseline/baseline.test.cjs
COURSE_VISUAL_OUTPUT=/tmp/music-apps-phase0 node --test tests/course-baseline/visual.test.cjs
# 可按迁移课单独回归；最终仍跑完整矩阵。
node --test --test-name-pattern='ET05|Motion' tests/course-baseline/visual.test.cjs
```

浏览器路径可由 `COURSE_CHROMIUM` 指定。其他环境如没有现成浏览器或 Playwright，不执行安装命令；说明缺少真实浏览器验证。测试服务只绑定 `127.0.0.1`，从磁盘或 Git 读取文件，无写入应用的接口；拦截所有外部请求，避免发送分析事件。

- `harness.cjs`：临时只读 HTTP 服务、原始源码提取、测试时钟、音频/设备/剪贴板替身。
- `baseline.test.cjs`：真实 Chromium 页面加载及原脚本交互，独立答案期望，检测合成信号，进度/报告/重试等行为；非试点原文件哈希和试点非 CSS DOM/JS 精确保护。
- `visual.test.cjs`：原页面与当前页面分别渲染，比较 body 全部元素以及 before/after 的计算样式、位置、尺寸、状态和文本；初始页/最终报告页再比较 PNG 哈希。完整状态截图可设 `COURSE_FULL_SCREENSHOTS=1`。
- `baseline.json`：起始提交、审计报告哈希、三课源码大小/行数、原内联 CSS 和 JavaScript 哈希。它不替代真实渲染。

截图输出位于 `COURSE_VISUAL_OUTPUT`，默认临时目录 `music-apps-course-baseline`；不提交数百张图片到仓库。每次从固定 Git 基线生成 `*-before.png` 与当前页面的 `*-after.png`，结果写 `summary.json`。PNG 哈希相等表示这次同浏览器、同模拟输入下截图相同，不是跨设备或真机保证。
