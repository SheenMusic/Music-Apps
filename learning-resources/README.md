# Course resources and dashboards — V1.0

- `course-catalog.js` owns official lesson titles, training types, current practice URLs and unmodified MusicTheory.net URLs. Formal lessons and supplementary resources are separate. Update a resource here once for both dashboards.
- `resource-links.js` renders titles with inline training links; it has no access/expiry decisions. Both training links open new tabs.
- Samuel's existing `students/samuel-b5def80cdaa55d42/student-data.js` owns progress, completed courses, `accessibleLessons`, `accessibleSupplementary` (resource IDs), and learning periods. No results or review statuses are inferred. To open supplemental A, add `harmonic-fourths-fifths` to `accessibleSupplementary`; B is `harmonic-simple-intervals`. Empty means the entire supplemental section is omitted.
- `/teacher/course-resources/` is a read-only resource navigator. `teacher-data.js` lists only student aliases and existing dashboard URLs; it does not import student records. Add no sensitive personal information or secrets.
- The repository and static assets are public. Link display, unlisted routes and `noindex` are not authorization. The catalog does not grant student access or change completion. V1 does not support sign-in, persistent online editing, or cross-device writes.
- Future authenticated editing needs server-side authentication, teacher roles/student scopes, private student data storage and an API with authorization and validation. Catalog data, student records and link rendering are separate so that they can later be loaded through that API. Do not add frontend passwords, tokens or localStorage-based shared administration.
